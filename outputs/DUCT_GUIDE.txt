FOLLOW PROJECT SYSTEM TYPES
In Step 3, enable Follow project system types to use existing HVAC system types for all groups. Exact IFC names are matched without case sensitivity, with surrounding whitespace ignored. If no name matches, an existing explicit mapping is retained; otherwise select a project type for that group. Unmatched selected groups block submission. New type creation is disabled in this mode. Turning the option off restores the previous per-group selections and new-type settings. The option maps System Type; IFC System Name is still stored as source metadata in Comments.
